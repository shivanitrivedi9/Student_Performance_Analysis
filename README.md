# Student_Performance_Analysis
Interactive Power BI dashboard analyzing 5,000+ student records to identify key factors influencing academic performance. The project uses data cleaning, DAX calculations, and data modeling to explore relationships between attendance, study habits, sleep, stress, and socioeconomic factors through dynamic visualizations.

# Project Objectives

The main objectives of this project were to:

Analyze patterns in student academic performance

Identify key drivers influencing grades and overall performance

Visualize relationships between lifestyle factors and academic outcomes

Build an interactive data analytics dashboard for exploratory analysis

# Tools & Technologies Used

Microsoft Power BI – Data visualization and dashboard development

DAX (Data Analysis Expressions) – Creating calculated columns and measures

Power Query – Data cleaning and transformation

Excel / CSV dataset – Data source

GitHub – Project version control and portfolio sharing


# Data Preparation

Data preprocessing was performed using Power Query in Power BI.

Steps included:

Removing unnecessary identifier columns

Renaming columns for better readability

Verifying correct data types for numerical and categorical fields

Handling categorical variables for analysis

# Data Modeling & Calculations

Several calculated columns and measures were created using DAX.

Calculated Columns

High Performer

Average Performer

Needs Improvement

Moderate (75–89%)

Low (<75%)

Sleep Category

Healthy Sleep (≥7 hours)

Sleep Deprived (<7 hours)

Measures

Example measures created in DAX:

Average Total Score

Average Attendance Percentage

Average Study Hours per Week

These measures were used to power key dashboard KPIs.

## Key Insights

Some key insights derived from the analysis include:

Students with higher attendance rates tend to achieve better academic results.

Increased study hours show a positive correlation with total scores.

Students with adequate sleep (7+ hours per night) perform better academically.

Lower stress levels are associated with improved academic performance.

Socioeconomic factors such as parent education and internet access may influence learning outcomes.
